编排逻辑（每期必须闭环）：

1. 条目五要素：项目链接、论文 | 技术报告链接、一句话描述、出处、卖点；
2. 开头一段说明本周新条目落在「可 hack 底座 → 训练基础设施 → 自进化 → 数据层 → 评测 → 自动科研闭环」主线的哪一环；
3. 结尾固定 **Recommended Stacks**（个人开发者/单卡可跑通完整闭环的最小组合）与 **Trends**。
