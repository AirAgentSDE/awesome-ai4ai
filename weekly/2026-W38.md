### 底层 Infra 封装 + 灵活训练 API

#### KDFlow（基线遗漏补收，2026-03）

- **项目链接**：https://github.com/songmzhang/KDFlow
- **论文 | 技术报告**：https://arxiv.org/abs/2603.01875
- **一句话描述**：解耦架构的 LLM 知识蒸馏框架——教师侧用 SGLang 推理、学生侧用 FSDP2 训练，只传 hidden states（零拷贝）并在学生侧重算 logits，同时支持 off-policy 与 on-policy 蒸馏及跨 tokenizer KD。
- **出处**：北京交通大学（BJTU）
- **卖点**：相比同类 KD 框架提速 1.44×~6.36×；on-policy 蒸馏是 RL 后训练之外「模型自我改进信号」的另一条工程管线，与主线的自进化环直接衔接；API 高度可扩展，07 月的更新又加了流式 hidden states 与异步传输。

## 数据层

#### CuratorKIT（基线遗漏补收，2026-06）

- **项目链接**：https://github.com/Lexsi-Labs/CuratorKIT
- **论文 | 技术报告**：https://arxiv.org/abs/2606.21631（配套方法论文 arXiv:2606.11127）
- **一句话描述**：把后训练数据管线的「摄入 → 清洗去重 → 卫生检查 → 合成生成 → 质量门 → 导出」收敛为单一可配置流水线的开源库，每个样本带 append-only 溯源链，被拒样本带结构化原因而非静默丢弃。
- **出处**：Lexsi Labs
- **卖点**：三点差异化——① 溯源精确 grounded 的幻觉门（对照生成来源 chunk 而非 judge 模型的泛化知识）；② 幻觉门与 reward 门捕捉不相交的失败人群，两者互补；③ 自适应恢复（诊断 → 修复 → 重新过门）在「必须用较小生成器」时收益最大。导出格式直接对接 TRL / Unsloth / AlignTune（含 GRPO/PPO rollout 格式），100+ LLM 后端经 LiteLLM。

## 评测

#### ResearchClawBench（本周活跃：09-17 leaderboard 刷新）

- **项目链接**：https://github.com/InternScience/ResearchClawBench
- **论文 | 技术报告**：https://arxiv.org/abs/2606.07591
- **一句话描述**：端到端自主科研基准——40 个来自真实已发表论文的任务、覆盖 10 个学科，agent 在含原始数据与文献的工作区内自主完成「探索 → 写代码 → 出图表 → 写报告」，再由多模态 LLM 裁判按专家标注的加权 rubric 对照目标论文评分。
- **出处**：SJTU / InternScience
- **卖点**：评分标尺直接对齐人类科学产出：50 分 = 复现论文结论，70+ 分 = 超越论文；当前最强 agent（Claude Code）均值仅 21.5，LLM frontier 均值 26.5，「re-discovery 尚未可靠达成」的可复现前沿。09-17 新增 InnoClaw 2.0（GPT-5.5）完整 40 任务结果（均值 34.89，agent 榜第 2），leaderboard 近三个月每周都在刷新——是继 PaperBench 之后社区刷榜最活跃的科研评测。内置 Claude Code / Codex CLI / OpenClaw / EvoScientist 等 8+ agent 预设与轻量 ResearchHarness 基线，自带实时流式 UI。

#### Agent²RL-Bench（基线遗漏补收，2026-04）

- **项目链接**：https://github.com/microsoft/RD-Agent/blob/main/rdagent/scenarios/rl/autorl_bench/README.md
- **论文 | 技术报告**：https://arxiv.org/abs/2604.10547
- **一句话描述**：考核「agent 能否自主设计、实现、调试并跑通完整 RL 后训练管线」的诊断型基准，6 个任务分三级——静态规则任务（GSM8K/HumanEval）、judge 信号任务（AlpacaEval）、闭环在线 RL（ALFWorld/WebShop/DeepSearchQA，12 小时预算）。
- **出处**：Soochow University / Microsoft Research Asia / Peking University
- **卖点**：直接回应 PostTrainBench 的盲区——静态基准上 SFT 就能拿高分，掩盖了 agent 不会「跑」RL 的事实；结论锋利：RL 管线仅在 ALFWorld 上成为最优解（4.85 → 93.28，SFT 预热 + GRPO 在线 rollout），多数成功路线仍是监督管线；附带运行时 instrumentation 与事后结构化 run 报告，能诊断 agent「如何搜索、失败与适应」。

## 自动科研闭环

#### scientific-agent-skills（基线遗漏补收，8 月底起持续屠榜，本周仍在增长）

- **项目链接**：https://github.com/K-Dense-AI/scientific-agent-skills
- **论文 | 技术报告**：—
- **一句话描述**：把任意 AI agent 变成「AI Scientist」的科研技能库——165 个经验证的即用 skill + 100+ 科学数据库（生物、化学、医学、药物发现），兼容 Cursor / Claude Code / Codex / Pi 及开放 Agent Skills 标准。
- **出处**：K-Dense-AI
- **卖点**：star 量验证需求真实（两周内冲到 4.5 万+，官方口径 19 万科学家使用）；「app store 化」的科研能力供给——药物发现 workflow（ChEMBL 查活 → RDKit 构效 → DiffDock 对接 → PubMed 耐药机制）与单细胞分析 workflow（Scanpy → Cellxgene → PyDESeq2 → Open Targets）均可在一次对话内由 agent 串完。对闭环主线的意义：闭环 agent 的「动手能力」不再各自从头造，开始走标准化 skill 接口。

#### DARE（de-anthropocentric-research-engine，本周更新 09-17）

- **项目链接**：https://github.com/yogsoth-ai/de-anthropocentric-research-engine
- **论文 | 技术报告**：—
- **一句话描述**：900+ 纯 markdown skill 构成的自主研究编排系统——10 个可自由组合的 research package（创意、收敛、洞察、压力测试、知识获取、实验执行、假设形成等），包内按 Campaign → Strategy → Tactic → SOP 四层命令层级组织，agent 可非线性调度并带显式回溯条件。
- **出处**：yogsoth-ai 社区
- **卖点**：「arsenal, not pipeline」的极端形态——没有任何应用代码与运行时，runtime 就是 coding agent 本身；2476 条 skill→skill 依赖边全部内联声明且机器验证闭合，单 clone 即带走完整可组合调用图；兼容 75+ agent harness。代表闭环编排层从「框架代码」向「纯指令资产」漂移：人类贡献从写程序变为写研究方法论。

#### Open Science Desktop（本周更新 09-18）

- **项目链接**：https://github.com/ai4s-research/open-science
- **论文 | 技术报告**：—
- **一句话描述**：本地优先、模型无关的开源科研工作台（Claude Science 桌面的开源替代）——Tauri + MCP + agent skills，把探索、文献调研、假设、实验代码、分析、图表、写作连成单一可审计会话，每个产物可回溯到生成它的代码、输入与对话。
- **出处**：ai4s-research 社区
- **卖点**：07-09 登顶 ResearchClawBench Pass@1 榜首——评测与工作台形成「裁判-选手」互相背书的飞轮；provenance by construction（`.openscience/provenance.jsonl` + append-only run log）；`osd` CLI 可无头跑在裸服务器上（同 UI、可脚本驱动、token 网关），把「桌面研究助手」变成可被另一个 agent 编程调用的服务。

#### The Station（基线遗漏补收，v2.0.0）

- **项目链接**：https://github.com/dualverse-ai/station
- **论文 | 技术报告**：https://arxiv.org/abs/2511.06309（v2 论文见项目页）
- **一句话描述**：开放世界多智能体科学发现环境——无中央管理器，agent 在持久世界中自主读论文、写笔记、相互讨论、跑实验并发表，产出的论文累积成其他 agent 可继续建设的共享文献。
- **出处**：DualverseAI
- **卖点**：与 autoresearch「单文件 + 单指标」的极简闭环构成光谱两极：任务要求可评分且单次迭代约 2 小时内完成即可接入（架构搜索、代码发现、优化、计算生物、数学构造、数据分析）；v2 报告了自主数学发现；Open Station 变体（700 ticks、五个前沿模型、无任务设定）展示了多模型在没有人类目标时的涌现动态。适合作为闭环系统的「社会环境」试验场。

## Recommended Stacks

面向个人开发者 / 单卡场景，能跑通完整闭环的最小组合（★ = 本周新收录）：

| 环节 | 选择 | 理由 |
| --- | --- | --- |
| 底座 | nanochat（或 autoresearch 自带 train.py） | 全栈最小实现，agent 可完整读懂并修改（维持基线推荐） |
| 训练 | 本地：Unsloth / LLaMA-Factory；托管：Tinker 或 Twinkle（接口兼容）；蒸馏：★ KDFlow | 本地零成本起步，托管免运维；需把大模型能力压进小模型时走 on-policy KD |
| 数据 | ★ CuratorKIT（合成 + 溯源质检 + 自适应修复）→ 导出 TRL/GRPO 格式 | 替代「合成脚本 + 祈祷」：每个样本可审计回源，被拒样本有结构化原因 |
| 评测 | PostTrainBench（后训练实操）+ ★ ResearchClawBench（端到端科研产出） | 一层考「会不会训练」，一层考「能不能做出科学结论」；ResearchHarness 基线可直接跑纯模型对照 |
| 闭环编排 | karpathy/autoresearch 的 program.md + train.py 模式为骨架；能力层挂 ★ scientific-agent-skills（科学工具）或 ★ DARE（研究方法论）；需要 GUI 与可追溯产物时用 ★ Open Science Desktop | 极简循环负责「不停转」，skill 库负责「会干活」，工作台负责「产物可信」 |

适用场景：单卡（H100 最佳，小配置可降门槛）跑无人值守 post-training 实验；想把闭环扩展到科研任务时，先用 ResearchClawBench 的 ResearchHarness 给自己的模型跑一次 40 任务基线，再决定编排形态。

## Trends

1. **闭环交付形态向 Agent Skills 收敛**：本周最活跃的三条新条目（scientific-agent-skills、DARE、Open Science Desktop）全部是 skills 形态而非框架代码——人类的贡献从「写闭环程序」迁移为「写可被任意 agent 加载的指令资产」，harness 无关性成为卖点（DARE 兼容 75+ agent）。
2. **科研评测进入「刷榜常态化」**：ResearchClawBench 三个月内每周刷新 leaderboard，09-17 刚挂出 InnoClaw 2.0 结果；「50 = 追平论文、70 = 超越论文」的锚点让不同代际的 agent/模型可以直接对表，评测本身成为闭环系统的竞技场。
3. **后训练评测从静态走向闭环在线 RL**：Agent²RL-Bench 揭示 PostTrainBench 类静态基准「SFT 即高分」的盲区，考核点移到「能否跑通在线 RL」；KDFlow 这类 on-policy 蒸馏 infra 的成熟，正在把「模型自我改进」从方法论文变成可调用管线。
4. **已收录基础设施持续高频迭代**：OpenRLHF 9 月新增 FlashREINFORCE（critic-free、单 rollout 异步 agentic RL，配置化组合），Unsloth Desktop 09-02 发版——底层 infra 环的竞争焦点转向异步化与 agentic 长程交互，而非峰值吞吐。
5. **极简循环与开放世界闭环开始分野**：autoresearch 一脉（单文件 + 单指标 + 时间预算）与 The Station 一脉（持久世界 + 多 agent + 共享文献）各自积累案例，中间态（蓝图驱动、桌面工作台）在两侧之间寻找平衡点，短期内不会收敛到单一形态。
